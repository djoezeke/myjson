## Generate documentation

### Mkdocs

If you want to see the documentation for a specific tag or commit hash, you can generate it as follows (here for tag
`v3.10.2`):

```bash
git clone https://github.com/djoezeke/myjson.git
cd myjson
```

> [!TIP]
> If you want to see the documentation for a specific tag or commit hash, you can generate it as follows (here for tag`v1.0.0`):
>
> ```
> git clone https://github.com/djoezeke/myjson.git
> cd myjson
> git checkout v1.0.0
> ```
>
> Generating/build process...

> Open URL <http://127.0.0.1:8000/> in your browser to see the documentation.
